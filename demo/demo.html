🔭 API Lens demo

1) Start this server (python3 server.py) and open this page.
2) Click the API Lens toolbar icon and press ● Record this tab (badge turns red and counts up).
3) Click the buttons below — each fires a real API call.
4) Open the workbench: calls are grouped into endpoints with inferred schemas. Export an OpenAPI spec or a typed client and check the login demo: the password is redacted in exports by default.
